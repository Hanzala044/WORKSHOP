# Backend integration contract

Foundation owner: core, database, shared Experiment, schemas, health/history/settings/pricepilot/voicemind routes, experiments/scraping/price comparison/Groq/speech services, main and requirements. Do not change original root files.

Other agent owns `app/api/routes/documents.py`, `rag.py`, `handvision.py`, their services/schemas/tests. Each route file exports `router = APIRouter(prefix="/documents" | "/rag" | "/handvision", tags=[...])`. Main mounts these under `/api/v1`. Please make these modules importable without optional ML dependencies or downloaded models. Main tolerates absent route modules during parallel work, but does not hide their import errors.

## Shared Python contracts (Python >=3.11)
- `app.core.config.Settings`, `get_settings()` (cached): `data_dir: Path`, `database_url: str | None`, `groq_api_key: SecretStr | None`, `groq_model: str`, `groq_transcription_model: str`, `allowed_hosts: list[str]` (EXACT scrape hostname allowlist, empty disables scraping), `trusted_hosts: list[str]`, `cors_origins: list[str]`, `max_upload_bytes: int`, `max_request_bytes: int`, `max_html_bytes: int`, `network_timeout: float`, `max_document_pages: int`, `max_document_chunks: int`. Env prefix `WORKSHOP_`, JSON arrays for list settings. Never return secrets/absolute paths to clients.
- `app.database.session`: sync SQLAlchemy `engine`, `SessionLocal` (expire_on_commit=False), `get_db()` yields Session, `init_db()` creates data directory/tables. No DB creation on module import. Default persistent SQLite is data_dir/workshop.sqlite3. SQLite foreign keys enabled.
- `app.database.models`: SQLAlchemy 2 `Base`, shared `Experiment`. UUID-string `id`, `module`, `title`, `status` (running/completed/failed), timezone-aware UTC `started_at`, nullable `completed_at`, JSON `input_summary` and `output_metadata`, nullable safe `error: str`, nullable `duration_ms: int`.
- Other agent defines DocumentMetadata/RAGSession/RAGMessage in **`app/models/documents.py`**, importing SAME `Base` from `app.database.models`. Own fields/relations; use UUID strings and UTC defaults. `init_db()` imports this file if present to register tables before create_all. Core does not define duplicate document/RAG models.
- `app.services.experiments.start_experiment(db, module, title, input_summary=None) -> Experiment` commits/refreshes row. `finish_experiment(db, experiment, output_metadata=None, error=None) -> Experiment` commits completed/failed state and elapsed duration. Only persist safe summaries, not raw documents, prompts, API keys or provider error bodies.
- `app.core.errors.APIError(status_code, code, message)`; global JSON error shape `{"error":{"code":"...","message":"..."},"request_id":"..."}`. Validation errors do not echo input. Provider/internal errors must not expose secrets or traceback.
- `app.services.groq_service.GroqService(settings=None)` exposes async `list_models() -> list[dict]`, `chat(messages: list[dict], model: str | None = None, temperature: float = 0.3) -> str`, `transcribe(content: bytes, filename: str, content_type: str, language: str | None = None) -> dict`. Uses real https://api.groq.com/openai/v1 endpoints, validates chosen model against /models, raises safe APIError. Optional request-scoped constructor with settings; monkeypatch httpx.AsyncClient for tests.
- No local speech synthesis is promised: `/voicemind/speech` returns a browser Web Speech descriptor, never fake audio.

## Foundation API
All under `/api/v1`: GET `/health` (database/storage/provider configuration diagnostics), GET `/history` (page/page_size/module/status), GET `/history/stats`, GET `/history/export?format=json|csv`, GET `/history/{id}`, DELETE `/history/{id}`; GET/PATCH `/settings` (safe process-local UI preferences only; never API keys or network policy); POST `/pricepilot/compare`; GET `/voicemind/models`; POST `/voicemind/chat`; POST `/voicemind/transcribe` (multipart `file`, optional `language`); POST `/voicemind/speech`.

Price compare body: `{"items":[{"url":"https://...","name_selector":"h1","price_selector":".price","currency":"USD"}],"permission_confirmed":true}`. Explicit scrape allowlist AND user permission AND robots policy required; no private IPs, no unchecked redirects. Exact decimal strings, mixed-currency groups, no exchange conversion or product identity guarantee.

Foundation requirements file includes FastAPI/uvicorn, SQLAlchemy, pydantic-settings, httpx, python-multipart, beautifulsoup4, pytest/pytest-asyncio. Other agent should communicate any additional dependencies in `backend/EXTRA_REQUIREMENTS.txt` rather than racing edits to requirements.txt. Optional ML dependencies must remain lazy. Tests use pytest with import path backend.
